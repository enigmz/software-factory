# Producto y criterios de interfaz

Prioridad: fiabilidad y trazabilidad antes que autonomía. No mostrar como
completada una integración que solo tiene contratos o simulaciones.
Separar aprobación, merge, despliegue y verificación de salud.

Si el proyecto incorpora interfaz, verificar escritorio y móvil, navegación por
teclado, etiquetas comprensibles, contraste y estados de carga, vacío y error.
Las capturas y la preview deben corresponder al commit revisado.

Este documento es una base para la factory; cada repositorio objetivo debe
definir además sus propios flujos y reglas visuales.
